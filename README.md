# Cake Délice — site de Lise (cake-delice.fr)

Site vitrine et bon de commande de Cake Délice, pâtisserie artisanale à Valence.
Créé et géré par DWT Digital (dwtdigital.fr).

- Hébergement : Cloudflare Pages, relié à ce dépôt.
- Branche `main` = site public cake-delice.fr (mise en ligne automatique à chaque modification).
- Les autres branches donnent une adresse de test (aperçu Cloudflare).
- Aperçu privé pour le mode « Pointer » de l'espace client : copie sur dwtdigital.fr (dossier apercu-cakedelice-…), à garder synchronisée.
- Les commandes partent vers le serveur de DWT Digital (Worker Cloudflare `dwt-admin`), qui les transmet à Lise par email.
